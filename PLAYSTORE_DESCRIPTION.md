## Full Description
catatin adalah aplikasi catatan sederhana dan modern untuk membantu Anda menyimpan ide, tugas, catatan kuliah, dan catatan project dalam satu tempat.

Fitur utama catatin:
- Multi akun lokal dalam satu perangkat
- Tambah, edit, dan hapus catatan dengan cepat
- Catatan tiap akun tersimpan terpisah
- Pencarian dan filter kategori
- Mode terang dan gelap
- Data tetap tersimpan di perangkat meski aplikasi ditutup

catatin cocok untuk:
- Mahasiswa
- Pelajar
- Pengguna personal
- Pengguna yang butuh aplikasi catatan ringan tanpa ribet

Semua data pada catatin disimpan secara lokal di perangkat. Anda bisa tetap menggunakan aplikasi ini tanpa koneksi internet dan tanpa perlu backend eksternal.

Kategori yang tersedia:
- Prioritas
- Kuliah
- Project
- Ide Baru

Dengan tampilan yang bersih dan pengalaman yang praktis, catatin membantu Anda tetap fokus, rapi, dan produktif setiap hari.
