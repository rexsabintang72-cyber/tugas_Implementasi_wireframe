# Privacy Policy for catatin

**Effective date:** May 8, 2026  
**Application name:** catatin  
**Package name:** com.ti24a6.app25

This Privacy Policy explains how `catatin` collects, uses, stores, and protects information when you use the application.

By using `catatin`, you agree to the practices described in this Privacy Policy.

## 1. Overview

`catatin` is a note-taking application that allows users to create local accounts, sign in on the same device, and manage personal notes. At the current stage of development, the application is designed to work primarily with local device storage and does not require a remote user database for its core note features.

## 2. Information We Collect

The application may process and store the following information on your device:

- account name
- email address
- password used for local sign-in
- notes, note titles, and note categories created by the user
- theme preference, such as light mode or dark mode
- local session information used to keep the last signed-in user connected

## 3. How We Use Information

The information handled by `catatin` is used only to support application functionality, including:

- creating and managing local user accounts
- allowing users to sign in and switch between stored accounts on the device
- keeping note data separated by account
- restoring the active sign-in session when the application is reopened
- storing user-created notes so they remain available after the application is closed
- remembering visual preferences such as theme mode

## 4. Local Storage and Data Processing

At the current stage, `catatin` stores account data, note data, and session data locally on the user’s device using local storage mechanisms made available by the operating system and application framework.

At this time:

- the application does not rely on a cloud database for its main note features
- the application does not sync note data across multiple devices
- the application does not create a remote user account on an external server for standard use

## 5. Data Sharing and Disclosure

`catatin` does not sell, rent, or trade personal information or note content to third parties.

The application does not intentionally transmit locally stored note content to a developer-operated backend server for analytics, advertising, or marketing purposes in its current version.

Information may only be disclosed if required to comply with applicable law, regulation, legal process, or enforceable governmental request.

## 6. Third-Party Services

`catatin` may use standard platform libraries, open-source dependencies, and mobile operating system services required for app functionality. These components support the operation of the application but are not intended to sell user data.

If future versions of the application integrate additional third-party services, this Privacy Policy may be updated accordingly.

## 7. Data Retention

Data stored by `catatin` remains on the device until one of the following occurs:

- the user logs out, where applicable to session state
- the user removes or overwrites note data through the app
- the user clears app storage from device settings
- the application is uninstalled from the device

If the application is removed from the device, locally stored data may also be removed by the operating system.

## 8. Data Security

We take reasonable steps to support secure handling of locally stored application data. However, no storage method or device environment can be guaranteed to be completely secure.

Because the current version of the application uses local credentials for sign-in behavior on the device, users are responsible for helping protect access to their device and keeping it secure from unauthorized use.

## 9. Children’s Privacy

`catatin` is not specifically directed to children under the age of 13, and the application does not knowingly collect personal information from children through an online service in its current implementation.

## 10. International Transfers

At the current stage, `catatin` does not intentionally transfer user note data to external servers for core application use. As a result, cross-border data transfer for primary note storage is not part of the standard feature flow in the current version.
